- **运营日志"点「查询」不重新取数"**：实测失败后连点两次都会重新取数，判断不成立。

- **c0e15de 输入长度按码元计**：只影响含生僻字或表情的分类名，风险低。

## 4. 用户授权代决的两项（2026-10-16）

1. **开发库备份在 Git 历史里（ebc7c6a）：不改写历史，改为防再犯。** 备份只有开发 / 模拟数据；生产管理员上线时另设口令，不复用。改写历史会让之后所有提交号失效（决策记录里引用了上百个），WorkBuddy 的克隆也会失配。新增提交前守卫 `test/config/no-db-backup.unit.test.ts`：Git 索引（含暂存区）里出现数据库备份就红。
