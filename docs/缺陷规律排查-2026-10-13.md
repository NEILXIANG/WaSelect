#### 🔴 高 2｜提交钩子的安全网对中文名路径静默失效（P13）

- **现象**：`gate:fast` 里的 `test:fast` 平时走 `vitest --changed HEAD~1`（按 import 图选用例），

  → **一条红的提交进了 main**。批次 6 改 `contracts/api-contract.yaml`（ASCII 路径）时才把它照出来。
- **修法**：三条 git 调用全部加 `-z`（NUL 分隔、路径原样），切分收进 `parseNulPaths()`。
- **提交**：`92ae8ab`。
- **验证**：注入（去掉 `-z` = 修之前的行为）→ 新用例精确红一条，其余 10 条绿：

## 3. 元结论：这两类问题为什么"测试全绿"

P12 与 P13 有一个共同点，也是本轮最值钱的观察：

**它们都不是"某处代码写错了"，而是"同一个事实存在第二个副本、或第二处判据"。**

- P12：`reason` 该进哪个参数，是**同一个事实**（"要不要给前端看"）在两个地方各判一次——
  写在代码里的位置（第 2 参 / 第 3 参），和契约 / 前端分支表里的期望。**两边都对不上时，
  每一层单独看都是对的**：服务端"确实有 reason"、前端"确实有分支表"，
  只是没有一个用例把两端接起来。
- P13：安全网的判据（"这个文件会不会被按内容读"）用**扩展名**代理了事实。
  代理失效时，守卫的表现与"通过"**完全一样**——没有信号、不报错、不红。

所以给这类问题的通用扫法是**两问 + 一动作**：
1. **同一件事实，这里是不是第二份？**（第二份 = 迟早漂移）
2. **这个判据的输入是什么？我能不能造一个反例让它"该触发而不触发"？**
3. 动作：把"**该跑的没跑**"与"**跑了但失败**"当成**同级**的信号。
   本轮两次最大的发现（P12、`test-fast` 的 `-z`）都来自第三个问题的变体：
   **"为什么全量 gate 才发现这条红？提交时为什么没拦住？"**

## 5. 给以后开发的建议

### 三句必答（每次修完一处，先回答这三句）

1. **同样的写法还在哪里？**——搜的是**写法**，不是关键词。
   （本轮 6 份「进行中售后」副本、3 处"reason 写错参数"，都是这样找出来的。）
2. **这条规则还有第二份实现吗？**——有第二份，就先合并，再修。
   （`rejectLocked` / `loginLocked`、四份状态词表、两份契约副本都是。）
3. **这句文案点名的按钮，承诺的结果在每个状态下都成立吗？**——文案失效是**静默**的：
   不报错、不红，只有用户会看到。

### 三条可复用的动作

1. **修完一个"该报错没报错"的问题，顺手问一句"为什么提交时没拦住"**。
   本轮两个最大的发现都不是从代码里扫出来的，而是从这个问题问出来的。
2. **抽公共函数时，先看有没有"按源码文本断言"的用例**（本仓有一批：`readFileSync` 读实现原文）。
   收紧断言、跟到定义处，**不要放宽**（放宽就是把缺陷锁进断言里）。
3. **同一路由的同一个码，必须有同一种响应形状**——"有时候有 `data.reason`、有时候没有"
   会让调用方只能按最保守的方式处理（`admin-order-fix-routes.ts:186-187` 已经把这个坑写下来了）。
   落实办法：把形状收进**一个** `throwGate()`，而不是 6 处各写一遍 `if (!gate.ok) throw new AppError(...)`。

## 6. 附：本轮踩过的环境坑（对下一个人有用）

| 坑 | 症状 | 处置 |
|---|---|---|
| 本机 `grep` 是 **toybox**，不支持 BRE 的 `\|` | `grep -rn "a\|b"` **静默失配**（看似过滤、实则不过滤）；中文场景更隐蔽 | 一律用 `grep -E` + `|`，或用 Grep 工具 / Python |
| 批量/长命令被看门狗 SIGTERM（exit 137） | `git commit`（要跑 pre-commit）必现；`grep … \| head` 也会 | 提交放后台跑（实测约 2m15s~2m30s）；退出码用 `cmd > log 2>&1; echo $?` 取，别用管道后的 `$?` |
| `NODE_OPTIONS` 里被注入了一个 stdout shim | 长输出命令报 `write EPIPE`，但退出码是 0 | 用 `env -u NODE_OPTIONS <命令>` |
| `git diff --name-only` 默认给非 ASCII 路径加引号 + 八进制 | **P13 本体**：门禁的安全网静默失效 | 给程序读路径一律加 `-z` |
| CI 免费额度已耗尽 | CI 全红但不是代码问题 | 本地跑全量 `npm run gate` 替代，别去改门禁来迎合 CI |
