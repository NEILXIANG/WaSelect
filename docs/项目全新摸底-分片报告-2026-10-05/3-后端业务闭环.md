# BIZ 分片：后端业务闭环摸底（2026-10-05，只读）

范围：`server/src/**`、`migrations/001–025`、`contracts/api-contract.yaml`（0.6.29）、文档库《技术文档》《支付方案-完整设计 v1.4》。
标记：【码】= 已读代码确认；【推】= 推断，未逐行验证；【文】= 只在文档里。
评判标准："上线后真实订单能从下单走到签收/售后，钱和货的账对得上。"

---

## 0. 一句话结论

**Stripe 银行卡这一条线，从报价、下单、支付、回调落账、发货到自动签收、全额退款、拒付标记，已经闭环，工程质量也高。** 只要配好 `sk_live_`/`whsec_`、域名和 CF Pages，就能收真钱。
但"账对得上"还差三块：
1. **微信支付完全没有代码**（不是骨架，是 0 行）。
2. **机构结算侧对账为 0**：手续费、到账日元、汇率都没回填，没有利润账。
3. **买家通知为 0**：邮件和订阅消息都只有配置键，没有发送代码。

此外，迟到付款和后台手工退款这两条"钱动了、系统不知道"的旁路只能靠人工，系统里不留账。

## 3. 跨境合规与清关

- **de minimis 取消已反映**：文档（README、技术文档 §2.5、支付方案 §6）统一为"2025-08-29 取消，日本原产 15%，DDP"。代码只允许日本原产（DB CHECK `products_origin_jp`，迁移 001），duty 按 `duty_rates` 表计算【码 + 文】。
- **申报字段**：
  - 商品层有 `hs_code / customs_desc_en / origin_country`。食品和化妆品必填 HS 码（`product-input.ts:297-305`）；7 个禁运或缓上标签上架即拒（`packages/shared/src/enums.ts:83-91`，`product-input.ts:292`）【码】。
  - 订单行只快照了 `declared_value_usd`。**`hs_code / customs_desc_en` 不进订单快照，管理端订单接口也不返回**（`orders-admin.ts:307` 只 select 到 declared_value_usd）→ 发货时要按商品逐个去查【码】。
- **Zonos / Ship&co：没有接入，也没有导出**。文档 §6 要求"每单发货前填 HS 码、英文品名、原产地、申报价值、重量"，并说 Zonos 支持 CSV/API 批量。代码里没有任何 CSV 或导出（grep 为空）【码】。
  - **上线必须（低成本版）**：做一个"待发货报关导出 CSV"，按 Zonos Prepay 的批量模板，字段取订单行快照加商品的 hs_code、英文品名、重量、收件地址。约 1.5–2 人日（Zonos 模板格式需实测，@measured）。
  - 之后：接 Zonos API 自动预付并取面单（5–8 人日）。
- **国家级禁运**：`country_profiles.blocked_tags` 已建，但报价和建单都不读【码】。MVP 只做美国，全局硬拒已经够用，属"之后"的事。
- **出口凭证（消费税免税）**：文档 §2.5a 要求留存受理证明，代码没有地方存凭证或附件。属运营 SOP，可以在发货时加"凭证编号/照片"字段（上线后一个月，1 人日）。
- **⚠️ 外部事实需复核（我未实测）**：文档写"日本邮便 2026-04-14 恢复对美收件、强制关税预付"，依据是素材库的官方表格。按 CLAUDE.md，素材只是线索；上线前要以日本邮便当期公告复核一次。

## 6. 安全与稳定

- **已做好**【码】：
  - 生产配置组合拦截（`config.ts:612+`）：生产禁 mock、禁残留 MOCK 密钥和 dev 登录；Stripe 密钥必须是 `sk_live_`，且与 whsec、CHECKOUT_BASE_URL 必须成对配置。
  - JWT：admin 12 小时，`token_ver` 支持即时撤权。
  - 管理员登录锁定加 IP 限流；限流挂在报价、建单、支付、登录、短链 5 个入口；回调用原始报文验签。
  - `x-powered-by` 已关闭；有出站熔断和超时预算；advisory lock 保证调度互斥；有心跳看门狗。
- **风险**：
  1. `render.yaml` 里 `PAYMENT_CHANNELS=mock` + `REVIEW_MODE=on` 是审核期配置（第 47-50 行）。**审核通过后切换到 stripe 是一次人工改配置**，要写进上线 SOP：关 REVIEW_MODE、删 MOCK_CALLBACK_SECRET、加 stripe 和三个密钥。配置校验会拦下错误组合，但拦不住"忘了切"。
  2. 限流计数在进程内存里（`rate-limit-memory.ts`），身份缓存也只在本进程作废。`numInstances: 1` 时成立，**扩到多实例就失效**；要扩时换 PG 或 Redis。
  3. 管理端除了邮箱密码没有第二因子。文档要求前置 Cloudflare Access（D-52），代码没法保证，必须写进部署检查清单。
  4. 汇率无过期保护（见 §1），属于钱的风险。建议报价时若汇率超过 N 天未更新就返回 50003，或至少告警（0.5 人日）。
  5. 对账产出只进日志（见 §5）。
  6. `payment_channels` / `app_config` 表没有接线，改通道的国家或币种要发版（已登记债务 R2-4），不影响上线。
