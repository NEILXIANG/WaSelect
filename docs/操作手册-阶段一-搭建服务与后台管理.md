# 阶段一：把「服务 + 管理后台」搭到网上（工作人员就能开始学后台）

> **本手册按「完全没有搭建服务经验」来写**：每个词第一次出现都解释，每一步只做一件事，每个命令都告诉你「粘贴到哪、按什么键、应该看到什么」。你不需要看懂命令的含义，**照抄、粘贴、回车**即可；看不懂的屏幕内容，截图发我。
> 目标：做完后，工作人员用浏览器打开一个网址、输入自己的账号，就能进入管理后台练习。
> 这一阶段**只搭 4 个东西**：数据库、API 服务、每日作业、管理后台网页。**不碰**：Stripe 真密钥、Cloudflare、域名、小程序（它们在后面阶段做，见 [完整手册](操作手册-staging搭建与小程序真机-新手版.md)）。
> 全程用平台送的免费网址，不需要买域名。
> 谁做什么：【你】= 只有你本人能做（注册、付款、点同意）；【我】= 可以让 Claude 做（核对、查日志、改配置）。你每做完一段，把结果或截图发给我，我帮你核对。
> 关于「界面示意」：Render 的页面需要登录才能看到，我没法替你截图。下面的方框图是**示意**（按官方文档的字段名画的），帮你知道「这一页上有什么、该填哪几格」，**以你屏幕上的实际文字为准，认关键词**。凡是我没能核实的地方标了 ⚠️。

## 00. 小白必读（5 分钟，后面所有步骤都靠这几个动作）

### 00.1 这件事到底在做什么？

你现在的整套系统（服务、数据库、后台网页）**只存在于你自己的电脑里**，关机就没了，别人也访问不了。
「搭建」就是**把它们租到互联网上一台 24 小时开着的电脑里**（这家公司叫 Render，租金按月收），这样：
- 工作人员在家里、在公司，用浏览器输入一个网址就能打开后台；
- 数据存在云端的数据库里，不会因为你的电脑关机而消失。

你不需要懂服务器。Render 会帮你做完「买服务器、装软件、办 https 证书」。你做的只有：**注册账号 → 填几个值 → 点几个按钮 → 等**。

### 00.2 几个词（大白话）

| 词 | 意思 |
|---|---|
| **服务 / API** | 在云端一直运行的程序，负责处理「登录、查订单、存商品」这些请求。后台网页和手机小程序都是在跟它说话。 |
| **数据库** | 存数据的地方（商品、订单、账号）。程序本身不存数据，都存这里。 |
| **管理后台** | 工作人员用的网页，在浏览器里打开。它自己不存数据，所有数据都是向「API」要的。 |
| **每日作业** | 每天凌晨自动跑一次的小任务（对账、检查卡住的订单），你不用管。 |
| **Render** | 出租服务器的公司。你在它的网页上点点按钮就能部署，不用碰服务器本身。 |
| **GitHub** | 存放代码的网站。Render 从这里把代码「取走」去运行。 |
| **Blueprint（蓝图）** | 一份配置文件，写着「我要哪几个东西、怎么设置」，Render 照着一次建好。我已经写好了，你只需要告诉 Render 去用它。 |
| **环境变量** | 程序启动时读取的「设置项」，比如数据库地址、密码。**不写在代码里**（写在代码里谁都能看到），而是在 Render 的网页上填。 |
| **日志（Logs）** | 程序运行时一行一行打印的「流水账」。出问题时看它。你不用看懂，复制给我就行。 |
| **部署（Deploy）** | 把代码装到云端并启动的过程，要等几分钟。 |

### 00.3 「终端」怎么用（第 6、7、9 步会用到）

**终端**是一个黑色（或白色）的窗口，你在里面打字，电脑照着做。你只需要会三个动作。

**① 怎么打开**：同时按 `Cmd + 空格`（Spotlight 搜索框弹出），输入 `终端`（或 `Terminal`），按回车。出现一个窗口，里面有一行以 `%` 结尾的文字，光标在闪——这就对了。

界面示意：
```
┌ 终端 ────────────────────────────────────────┐
│ neilxiang@MacBook ~ %  █                      │ ← 光标在这里，等你输入
└──────────────────────────────────────────────┘
```

**② 怎么运行手册里的命令**：手册里灰底的框就是命令。
1. 用鼠标选中框里**全部**文字，`Cmd + C` 复制；
2. 点一下终端窗口，`Cmd + V` 粘贴；
3. 按回车（`Return`）运行。
4. **一次只粘贴一个框**，等它跑完（再次出现 `%` 提示符）再粘贴下一个。

**③ 出错了怎么办**：终端里出现红字或一堆英文，**不要慌，也不要自己改**。选中全部输出，复制，发给我。命令几乎不可能「搞坏」什么——它们都是读或设置，我已经让危险的命令必须加 `--yes` 才执行。

> 特别说明：有的命令会让你「粘贴一个地址」，粘贴时**屏幕上什么都不会显示**（这是故意的，为了保密，不是卡住了）。粘完直接按回车。

### 00.4 浏览器里点按钮的小规矩

- 平台的界面会不定期改版，**按钮的位置、颜色会变**，所以手册里按钮名字用「」括起来，你**找文字，不要找位置**。
- 找不到某个按钮：先看看是不是在页面**更下面**（滚动），或在**菜单（⋯ 或头像）**里。还找不到就截图发我。
- 页面上任何带「Delete / 删除」的按钮，**手册没让点就别点**。

### 00.5 三条安全规矩

1. **密钥、口令、数据库地址只放密码管理器**（macOS 自带的「密码」App 就行）。不要发给任何人，包括我；不要贴到聊天里；不要存在桌面文档里。
2. **每次你要把东西粘进网页或终端，先确认是从密码管理器复制的，不是别的**。
3. 手册里「**预期值 / 示例**」的字（比如 `you@gmail.com`、`sk_test_placeholder…`）要**换成你自己的**，别原样照抄邮箱。

| 你看到 | 原因 | 怎么办 |

## 6. 给自己开通「手机验证」（10 分钟）【你】

### 6.1 为什么

staging 和生产**强制**管理员必须开手机验证（TOTP）才能登录——只有口令进不去。服务启动时已经用你填的邮箱和口令自动建好了你的管理员账号，现在给它开手机验证。

### 6.2 拿到数据库地址

1. Render → 数据库 `waselect-staging-pg` → 「**Info**」（或右上「**Connect**」菜单）。
2. 复制「**External Database URL**」。形如（示例，**不是真的**）：
   ```
   postgresql://waselect:AbCdEf123456@dpg-d3abcde5f6g7h8-a.oregon-postgres.render.com/japan_shop_staging
   ```
3. 存进密码管理器。**它等同于数据库的钥匙**，别发给任何人。
4. 官方说明：外部连接必须加密，Render 会拒绝 `sslmode=disable`；下面命令会自动补上 `?sslmode=require`。数据库默认任何 IP 都能连（只要口令对）。

### 6.3 运行命令

> **这段命令在做什么**：连上云端数据库，给你的管理员账号打开「手机验证」，并告诉你一串密钥。命令里 `read -s` 那一行是「请你粘贴数据库地址」。**你只需要：把里面的邮箱换成你自己的，然后整段粘贴到终端、回车。** 终端用法不熟，先回看 00.3。


终端里**整段复制**（`read -s` 会等你粘贴数据库地址，**粘贴时屏幕不显示字符，粘完直接回车**）：

```bash
cd /Users/neilxiang/Documents/me/jp_project
export PATH=/Users/neilxiang/.workbuddy/binaries/node/versions/22.22.2-6/bin:$PATH

read -s "DATABASE_URL?粘贴 External Database URL 后回车（输入不会显示）: "
export DATABASE_URL="${DATABASE_URL}?sslmode=require"

# 邮箱换成你在第 3 节填的 ADMIN_EMAIL
npm run admin:totp -- you@gmail.com --yes

unset DATABASE_URL
```

**应该看到**（示意）：
```
[admin:totp] 目标库：…render.com/japan_shop_staging
[admin:totp] 已开通（或已换密钥）；该管理员现有会话已全部失效。
把下面任意一行录入验证器 App（Google Authenticator / 1Password 等），然后清屏：
  密钥：JBSWY3DPEHPK3PXP
  URI ：otpauth://totp/...
此后登录：口令 + App 上的 6 位码。
```

### 6.4 把密钥录进手机

- **iPhone「密码」App**：新建一条 → 「设置验证码 / Set Up Verification Code」→ 「输入设置密钥 / Enter Setup Key」→ 粘贴上面的密钥。
- **Google Authenticator**：右下「+」→「输入设置密钥」→ 账号名填 `WaSelect staging`，密钥填那串，类型选「基于时间」。

录好后 App 里会出现一个 6 位数字，每 30 秒变一次。

**然后立刻**：① 把密钥存进密码管理器；② 终端按 `Cmd+K` 清屏；③ 这串密钥**不要发给任何人（包括我）**。

### 6.5 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 报 `没有这个管理员` | 服务还没成功启动过（管理员是启动时建的）→ 回第 5 节确认 API 是 Live |
| 报 SSL / 连接相关错误 | 确认地址完整，命令里 `?sslmode=require` 已加 |
| 之后验证码总是不对 | 手机时间不准：设置 → 通用 → 日期与时间 → 打开「自动设置」 |
| 手机丢了 / 换手机 | 重新运行本节命令（生成新密钥，旧的作废） |

## 11. 出问题怎么办

| 症状 | 最可能的原因 | 办法 |
|---|---|---|
| 服务一直重启，日志有「启动失败」 | 某个环境变量缺失或格式不对 | 看日志列出的变量名，到 Environment 补 |
| 后台能打开，登录一直失败 | 没开手机验证 / 验证码过期 / 手机时间不准 | 见 6.5 |
| 登录后列表空白，浏览器控制台有跨域错误 | `CORS_ORIGINS` 与后台实际地址不一致 | 对比二者，必须精确（https、无结尾斜杠） |
| 忘了口令 | | 重新运行 7.2 的命令设新口令 |
| 员工手机丢了 | | 重新运行 6.3 的命令（针对该员工邮箱） |
| 报价提示「运费不可计算」「汇率不可用」 | 没录或汇率过期 | 见第 8 节 |

**找我帮忙时，一次性贴出**：① 你在第几步；② 报错原文或截图；③ Render 日志里出错位置前后各 20 行。
**不要贴**：口令、`sk_`/`whsec_` 开头的密钥、数据库地址、验证器密钥。
